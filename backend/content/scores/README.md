# PDF-ноты

Сюда кладутся PDF-файлы нот (по одному на произведение, имя — `<id>.pdf`).
Папка НЕ раздаётся как статика: файлы выдаются только через защищённый
эндпоинт `GET /api/scores/:id/download` (нужен вход и активный Pro).

Как добавить: `npm run add-score -- --file путь/к/файлу.pdf --id minuet-g --title "..." ...`
(см. README в корне репозитория) или вручную: положить файл сюда и добавить запись в `../scores.json`.
